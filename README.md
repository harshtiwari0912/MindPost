application that allows users to register, log in, and share their thoughts through posts. Users can like others' posts, edit their own, and upload profile pictures. The app features secure authentication using JWT, password encryption with bcrypt, and uses MongoDB for data storage. Views are rendered using EJS, and static assets are served via Express. This project demonstrates core backend concepts such as RESTful routing, middleware, and session management. MindPost provides a clean, minimal platform for open expression and interaction, making it ideal for beginners learning full-stack development.
